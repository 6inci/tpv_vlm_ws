## 0. 연구의 주 작업 (사용자 정의 2026-11-15)

> 고정된 외부 RGB 영상에서 자연어 작업지시를 해석하고, 객체의 상태와 공간 관계를 활용하여 올바른 작업 대상 및 목적지를 선택한 후, 이미지 기반 경로계획에 연결하는 것.

- 블록의 실제 파지·운반과 Nav2 주행은 현재 평가 범위가 아니다.
- 따라서 위험도는 **목적지 선택**으로 본다. 기준은 세 가지다:
  - 올바른 선택
  - 잘못된 선택
  - 판단 보류
- 물리적 충돌은 이 단계에서 검증하지 않는다.

## 1. 평가 단위 (확정)

| 항목 | 정의 |
|---|---|
| 주 평가 대상 | 새 dev 8배치의 소형 팔레트 16개, **프레임 0만** |
| 프레임 1–2 | 반복성 평가에만 쓴다 (프레임 0과 같은 답인가). 독립 표본으로 세지 않는다 |
| 독립 단위 | 배치 (8개). 통계는 배치 단위로 다시 뽑는다 (배치 묶음 bootstrap) |
| "정답" | 프레임 0에서 빈/적재 상태가 맞음. 형식 오류는 정답이 아니다 |

## 2. 상태 오판 (확정)

| 이름 | 정의 | 목적지 선택에서 생기는 일 |
|---|---|---|
| **A** (E1) | 실제 빈 팔레트 → 적재로 판단 | "블록이 있는 팔레트"를 찾을 때 빈 팔레트가 후보로 들어와 오선택이나 모호(보류)가 된다. "빈 팔레트"를 찾을 때는 정답 팔레트가 빠져 "없음"(보류)이나 다른 팔레트 선택이 된다 |
| **B** (E2) | 실제 적재 팔레트 → 빈으로 판단 | "빈 팔레트"를 목적지로 찾을 때 **이미 블록이 있는 팔레트가 빈 목적지 후보가 된다.** 이것이 선택되면 점유된 팔레트를 목적지로 고르는 잘못된 선택이다. "블록이 있는 팔레트"를 찾을 때는 정답이 빠져 보류나 다른 선택이 된다 |

- B를 중요하게 평가하는 이유: 잘못된 작업 목적지 선택으로 바로 이어진다 (사용자 판단).
- 형식 오류는 A, B가 아니라 E7로 센다.
- 위 결과가 실제로 오선택이 될지 보류가 될지는 같은 배치의 다른 팔레트 판단에 따라 달라진다. 그래서 §5의 목적지 선택 분석으로 직접 센다.

## 3. dev 선별 규칙 (확정, `config.json` screening_rule)

- 용도: **test에서 확인할 확대 조건을 고르는 dev 선별.** 통계적 유의성이나 최종 가설 입증이 아니다.
- 정의
  - 순개선 net = (확대 조건에서 프레임 0 상태가 맞은 팔레트 수) − (Z-full의 같은 수). 같은 16개 팔레트 기준이다.
  - k = 3
- 규칙 (Z-crop, Z-both 중 **최대 하나**만 고른다)
  1. B(적재→빈) 수가 Z-full보다 늘지 않을 것
  2. net ≥ 3
  3. 둘 다 통과하면 net이 더 큰 조건
  4. net이 같으면 프레임 0의 호출당 추론 시간 중앙값이 짧은 조건
  - 둘 다 통과하지 못하면 고르지 않고 탐색 결과를 그대로 보고한다.
- 함께 보고하는 것 (선별 규칙에는 쓰지 않음)
  - 배치 묶음 bootstrap 95% CI (net, 배치 8개 재표집, 2000회, seed 0)
  - A(빈→적재) 수
  - 바닥 블록 오판
  - 색 완전 일치
  - 반복성
  - 목적지 선택 결과
- k = 3의 의미 (`analysis/k_screen_20261115T152710/`, 계산만 함)
  - 효과가 없어도 우연 통과 0.19–0.35
  - 큰 개선(정확도 0.5 → 0.8)은 0.82로 통과
  - 그래서 선별로만 쓴다.
- 독립 test의 최종 판정 기준은 test 실행 전에 따로 확정한다.
  - 같은 k = 3을 test에 쓰면 우연 통과가 0.26–0.44다. 더 엄격한 기준이 필요하다.

## 5. 목적지 선택 분석 (위험도를 목적지 관점으로 재는 방법)

- 같은 실행의 팔레트별 답에서 Python이 다음 네 가지를 고른다 (EXP120 resolve 규칙):
  - "빈 팔레트"
  - "블록이 있는 팔레트"
  - "파란 블록이 있는 팔레트"
  - "빨간 블록이 있는 팔레트"
- 비교 대상: 정답 상태로 같은 선택을 한 결과.
  - 상태 조건만 있고 거리 상수가 없으므로 정의에서 바로 나온다. 관계표의 사람 판정이 출처다.
- 결과 분류 (배치 8 × 질의 4 = 32개)
  - 올바른 선택
  - 잘못된 선택 (정답이 있는데 다른 것)
  - 놓침 (보류)
  - 올바른 보류
  - 정답 없는데 선택
- 형식 오류 팔레트는 "상태 모름"으로 두고 선택에서 뺀다. 그래서 E7의 영향이 여기서 보인다.
- 새 실험이 아니라 같은 출력의 계산이다.
