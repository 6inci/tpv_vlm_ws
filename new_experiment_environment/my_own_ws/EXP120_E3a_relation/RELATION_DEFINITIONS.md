# E3a 관계 정의 (새 촬영 데이터용) — 2026-11-15

- 상태
  - "가장 가까운" = **확정** (사용자 결정 2026-11-15)
  - "옆" = **잠정 정의.** 새 dev에서 검증한 뒤 사용자가 확정한다.
- 원칙
  - 정답은 사람이 눈으로 판단한다. Python 규칙(J-geo)이나 모델 출력으로 만들지 않는다.
  - 이 정의는 dev P01–P04 결과에 맞추지 않는다. P01–P04는 관계 정의를 정하는 데 쓰지 않는다.
  - 정답은 모델 실행 전에 기록한다.

## 1. 가장 가까운 (closest to X) — 확정

- 후보 소형 팔레트끼리 X까지의 거리를 비교해, 가장 가까운 하나를 고른다.
- 절대 거리 임계값이 없다. 모두 멀어도 답이 있다.
- 답이 없는 경우: X가 장면에 없음 → "확인 불가".
- 모호
  - 사람이 눈으로 볼 때 어느 쪽이 더 가까운지 구분되지 않으면 "모호"로 기록한다.
  - 숫자 기준은 정하지 않았다. 이전 제안(팔레트 한 변)은 철회하고, 새 dev에서 사람 판단과 측정 거리를 함께 기록해 둔다.
- 거리: 팔레트 윤곽과 X 윤곽 사이의 가장 짧은 바닥 거리. 지금은 이미지에서 판단한다.

## 2. 옆 (next to X) — 잠정 정의, 새 데이터에서 검증

- 말로 된 정의 (사람 판단용)
  - 팔레트가 X 바로 곁에 놓여 있다.
  - 둘 사이에 다른 물체가 없다.
  - 사람이 "X 옆에 있는 팔레트"라고 말할 때 자연스럽게 가리킬 위치다.
- 답이 없는 경우
  - 옆에 있는 팔레트가 없음 → "없음"
  - X가 장면에 없음 → "확인 불가"
- 둘 이상이 옆에 있으면 "모호".
- 숫자 기준(간격 몇 px 이하 등)은 **지금 정하지 않는다.** 아래 §3에서 새 dev로 검증한 뒤 사용자가 정한다.

## 3. 새 데이터에서의 검증 절차

1. 촬영: EXP111 `CAPTURE_PLAN.md` §3.1의 간격 단계(붙음 / 가까움 / 떨어짐)와 "사이에 물체" 조건을 포함한다.
2. 사람 판정
   - 촬영 직후, 모델 실행 전에 한다. 숫자를 재지 않고 눈으로 판단한다.
   - 장면의 팔레트와 기준 물체(트럭, 충전기, 카트, 라바콘) 쌍마다 다음을 기록한다:
     - "옆 / 옆 아님 / 애매"
     - "사이에 물체 있음"
3. 측정: 정답 박스에서 쌍마다 간격(px)을 계산한다.
   - 이미지 픽셀이며 왜곡 보정 전이다.
   - 실제 바닥 거리는 homography 이후의 과제다 (지금은 하지 않음).
4. 검증 (새 dev, 기술 통계만)
   - 사람 판정별로 간격 분포를 보고한다.
   - 후보 숫자 기준이 사람 판정과 얼마나 맞는지 보고한다. 후보 예: 팔레트 한 변의 k배, 기준 물체 긴 변의 k배.
5. 결정 (사용자)
   - 정답: 사람 판정을 그대로 쓴다.
   - J-geo 규칙 상수
     - 시스템 설정이다. 바꾸려면 새 판으로 기록하고 사용자 승인을 받는다.
     - 지금 EXP120의 값(기준 물체 긴 변 × 1.0, 모호 × 0.2)은 가능성 검증용으로 그대로 둔다.
6. test에서 확인: 설정을 확정하고 사용자가 승인한 뒤 한 번만 본다.

## 4. 기록 형식 (배치마다 하나, 사람이 작성)

`annotations_relations/<layout>.json` (예시)

```json
{
 "layout": "D03",
 "annotator": "<이름>",
 "written_before_model_run": true,
 "pallet_ids": "x-order, 1 = leftmost pallet in the frame",
 "blocks": {"red": "on:1", "blue": "floor_near:2"},
 "next_to": {"1": {"charger": "yes", "cart": "no"}, "2": {"charger": "unclear", "obstacle_between": {"charger": true}}},
 "closest_to": {"truck": "1"},
 "e3a_answers": {"e01": "1", "e02": "none", "e03": "2"}
}
```

- 블록 값
  - `on:<팔레트>`: 팔레트 위
  - `floor_near:<팔레트>`: 그 팔레트 가장자리에서 블록 2개 폭 이내의 바닥
  - `floor_far`: 그 밖의 바닥
  - `absent`: 장면에 없음
- 블록은 빨강, 파랑 하나씩이므로 색으로 구분한다.
