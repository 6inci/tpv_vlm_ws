# P01 의미 구역 이름 초안 v2

**상태: DRAFT — 사용자 확인 전에는 경로 계획이나 안전 판정에 사용하지 않음.** 기존 `zones_draft.json`과 overlay는 보존했다. 이 초안은 같은 P01 raw 왜곡 이미지(1920×1080)의 **장소 이름**을 추가한다. 다각형은 픽셀상의 대략적인 시각 경계이며 월드 좌표가 아니다.

| ID | 제안 이름 | 해석 | 경계 근거 |
|---|---|---|---|
| Z01 | 보행 통로 | 사람의 이동 통로 | 초록색 바닥과 발자국 |
| Z02 | 로봇 주행 구역 | 노란 외곽선 안의 기본 이동 영역 | 사용자의 ‘로봇이 움직일 도로’ 설명 |
| Z03 | 중앙 화물 적치 구역 | 박스 더미를 둔 섬 | 별도 노란 테두리 |
| Z04 | 자재 보관·적치 구역 | 카트·IBC·드럼통을 둔 섬 | 별도 노란 테두리 |
| Z05 | 충전 구역 | 로봇 충전 목적지 후보 | 번개 그림과 충전기 |
| Z06 | 트럭 하역장 | 트럭이 서 있는 목적지 후보 | 트럭과 흰 점선 주차 경계 |
| Z07 | 왼쪽 컨베이어 작업셀 | 컨베이어·로봇 팔 작업공간 | 왼쪽 흰 경계 |
| Z08 | 상단 로봇 팔 작업셀 | 로봇 팔 두 대의 작업공간 | 상단 흰 경계 |
| Z09 | 작업자 준비·사물함 구역 | 사물함·개인 보관함·작업대 주변 | 물체 묶음; 바닥 경계는 불명확 |

| L01 | 소화기 배치점 | 안전 설비 위치 **점** | 소화기 물체. 독립된 바닥 구역 경계는 보이지 않음 |

P01 정답 박스 **중심점** 확인 결과, `Z06`에는 트럭·트럭 짐칸 상자, `Z07`에는 컨베이어·로봇 팔, `Z08`에는 로봇 팔 2대, `Z09`에는 사물함·개인 보관함·작업대, `Z10`에는 선반 2대, `Z05`에는 충전기 2대가 들어간다. 이는 이름 초안의 위치 점검이며 물체 전체가 polygon 안에 들어간다는 뜻은 아니다.

## 이동 규칙과 지도의 층

- 사용자의 설명대로 `Z02`를 로봇 이동의 **외곽 범위**, `Z01`을 사람 통로로 제안했다. 사람과 로봇이 서로의 통로에 들어갈 수 있는지는 아직 미확정이다.
- `Z03`과 `Z04`는 `Z02` 안에 있다. 따라서 실제 주행 가능 영역은 단순히 `Z02` 내부 전체가 아니다. 물체 점유 영역·안전 여유를 빼고 연결성을 검사해야 한다. 현재 픽셀 다각형만으로 충돌 안전을 보증할 수 없다.
- 충전 구역 `Z05`와 하역장 `Z06`은 `Z02`의 노란 외곽선 밖에 있다. 그림에 출입 연결부가 분명하지 않아, 이곳으로 로봇이 들어갈 수 있는지와 허용 지점을 별도 지정해야 한다.
- `L01`은 소화기 **위치**다. 이를 ‘소화기 구역’으로 확대하려면 별도의 바닥 경계 또는 사용자가 정한 안전 반경이 필요하다.
- `Z07`과 `Z08`은 서로 다른 흰 테두리지만 ‘작업공간’이라는 상위 이름으로 묶을 수 있다. 자연어 지시가 ‘작업장’만 말할 때 둘 중 어느 쪽인지 추가 단서가 필요하다.

## 사람 검토가 필요한 결정

1. 초록 `Z01`은 **사람 전용**인가요? 로봇은 진입 금지인가요, 필요 시 횡단 가능한가요?
2. 노란 `Z02`는 로봇이 주행 가능한 **외곽**이 맞나요? `Z03/Z04`에는 접근은 가능하되 내부 통과는 금지하는 규칙이 맞나요?
3. 로봇이 하역장 `Z06`과 충전 구역 `Z05`로 이동할 때 노란 경계를 **어디로 통과**하나요? 지정된 진입점이 없다면 경계 근처의 도달점을 목표로 삼을까요?
4. 왼쪽의 사물함·작업대 `Z09`, 흰 테두리의 작업셀 `Z07/Z08`을 각각 분리하는 이름이 맞나요, 아니면 하나의 ‘작업 공간’으로 묶을까요?
5. 소화기는 `L01`처럼 위치 표식만 둘까요, 아니면 보호 반경이 있는 안전 구역으로 정의할까요?

## 연구 설계상 구분

- **의미 지도:** ‘하역장으로 가라’의 장소 ID를 결정한다. VLM은 장소 이름·대상을 해석할 수 있다.
- **기하 지도:** raw 픽셀 다각형을 검토한 뒤 바닥 좌표로 변환한다. 높이 있는 물체의 이미지 박스 중심을 그대로 바닥 좌표로 쓰지 않는다.
- **계획 지도:** 로봇 footprint와 장애물 여유를 적용해 주행 가능한 영역과 목표 접근점을 계산한다. 장소 polygon의 중심을 곧바로 경로 목표로 사용하지 않는다.

예를 들어 ‘트럭 하역장으로 이동’은 `Z06`을 찾는 문제와 **도로에서 실제로 닿을 수 있는 하역 지점**을 고르는 문제로 나뉜다. ‘소화기 옆’은 `L01` 주변의 위치 관계를 해석해야 하며, 소화기 박스 중심으로 주행하라는 뜻이 아니다.
