- 상태: **계획.** 촬영 전이다. 카메라 설치 위치와 촬영 조건은 사용자가 현장에서 확인한다.

## 2. 촬영 명령

작업 폴더는 `my_own_ws/EXP110_word_grounding`, Python은 `qwen_vl`이다.

```
python tools/capture.py --split dev  --layout D01 --note "<배치표 내용 그대로>" --out ../EXP111_small_objects/data/dev
python tools/capture.py --split test --layout T01 --note "<배치표 내용 그대로>" --out ../EXP111_small_objects/data/test
```

- 미리보기에서 `c`를 누르면 3프레임(0.5초 간격, PNG 무손실, 왜곡 보정 전 원본)이 저장된다. 기존 파일은 덮어쓰지 않는다.
- **test 봉인**: T16까지 촬영한 직후 `cd ../EXP111_small_objects && sha256sum data/test/* > TEST_SEAL_<날짜>.sha256`을 실행한다. 정답 작성 외에는 설정이 확정될 때까지 test를 열지 않는다.
- 형식 주의: EXP110은 Cheese JPEG, 새 촬영은 PNG다. EXP111의 dev(새 PNG)와 test(PNG)는 형식이 같다.

#### 세는 단위 (2026-11-15 정정)

- 이전에 적은 "dev: G0 3, G1 4, G2 2, O 1 (합 10)", "test: G0 5, G1 10, G2 3, O 2 (합 20)"은 **배치 수가 아니라 간격을 지정한 팔레트 수**였다.
  - 한 배치에 팔레트가 2개라서, 두 팔레트 모두 간격을 지정한 배치는 2로 센다.
  - 그래서 합계가 배치 수(8, 16)와 다르다.
  - 배치를 중복으로 센 것은 아니다. 단위 표기가 빠졌던 것이다.
- **촬영 배치 수는 바뀌지 않는다** (dev 8, test 16).
- 독립 단위는 배치다. 한 배치 안의 두 팔레트는 독립이 아니다.
- 역할 교환 쌍은 같은 자리에 팔레트를 놓는다. 그래서 그 자리는 위치로서 두 번 세지 않는다.
  - 해당 쌍: D01/D02, T01/T02, T03/T04, T05/T06

## 5. 정답 작성

- 배치마다 프레임 0에 정답을 만든다. AI 초안 → 사람 검토이며, EXP110 `tools/annotate.py`를 쓴다.
  - 저장 위치를 EXP111 아래로 지정한다 (EXP110 정답과 섞이지 않게).
  - 명령: `python tools/annotate.py ../EXP111_small_objects/data/dev/*_f00.png --annotator <이름> --out ../EXP111_small_objects/annotations`
  - 결과 파일: `EXP111_small_objects/annotations/dev/<layout>_f00.json` (EXP112 `config.json` data.boxes와 같음)
  - 대상: 소형 팔레트 박스, 블록 박스와 색, 팔레트 상태(EMPTY / LOADED), 바닥 블록 여부
- E3a 관계 정답은 사람이 배치마다 기록한다. Python 규칙으로 자동 생성하지 않는다(순환 평가 방지).
  - 기록 형식: 질의마다 정답 팔레트 ID, 또는 "없음 / 모호 / 확인 불가"
- 관계표 (2026-11-15 추가): `annotations_relations/<layout>.json`. 형식은 EXP120 `RELATION_DEFINITIONS.md` §4를 따른다.
  - 박스 도구(annotate.py)는 이 정보를 저장하지 못하므로 따로 기록한다. 들어가는 내용:
    - 블록마다 위치: 팔레트 위 / 가까운 바닥 / 먼 바닥 / 없음
    - 팔레트와 기준 물체 쌍마다 "옆 / 옆 아님 / 애매"와 "사이에 물체"
    - E3a 질의 정답
  - 모델 실행 전에 쓰고, 숫자를 재지 않고 눈으로 판정한다.
  - EXP112(H-zoom)의 적재 관계 정답도 이 표의 블록 위치를 쓴다.
- 프레임 1–2는 카메라와 물체가 같으므로 같은 정답을 쓴다. 이 프레임들은 출력이 얼마나 일관된지 재는 데만 쓴다.
- test 정답은 모델을 test에 돌리기 전에 완성하고 해시를 기록한다.
