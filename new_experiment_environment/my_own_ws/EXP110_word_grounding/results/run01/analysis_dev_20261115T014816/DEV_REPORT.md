## 5. 이 결과가 시스템에서 쓰이는 곳

"파란 블록을 소형 팔레트로 옮겨" → (1) 단어 → 화면 박스 **[EXP110 평가 대상]** → (2) 화면 박스 → 바닥 좌표 (팀원, homography) → (3) 경로·주행.

1. (1)에 넣을 방식 선택의 근거: C6-dino (잠정). 논문 주장 "검출기를 붙이면 Qwen이 더 잘 찾는다"는 test로 판정.
2. 어떤 물체를 믿을지의 근거: 큰 고정 물체(트럭, IBC, 박스 더미)는 믿을 만함. 블록·소형 팔레트는 현재 방식으로 믿을 수 없음 — 그대로 쓰면 "파란 블록"이 파란 드럼통으로 잡힘.
3. 다음 단계 설계의 근거: 블록은 소형 팔레트 주변을 잘라 확대한 뒤 다시 묻는 방식이 필요 (INFERRED). 박스를 받아들이기 전 크기·위치로 확인하는 결정론적 검증 단계 필요.
