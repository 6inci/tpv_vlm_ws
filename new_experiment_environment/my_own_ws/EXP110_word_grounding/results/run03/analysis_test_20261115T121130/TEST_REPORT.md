  - McNemar exact p = 0.0026 (불일치 쌍 28 / 9).
  - 이 검정은 (질의, 배치) 쌍을 서로 독립으로 가정한다. 실제로는 영어 질의 49개 중 C1 43개, C6 39개가 6장 모두에서 같은 결과였다. 그래서 p가 과소평가되므로 주 근거로 쓰지 않는다.
