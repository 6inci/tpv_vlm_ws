## Classification notes

- **VALID_CURRENT_RESULT**: latest evidence currently used for the detector comparison.
- **VALID_BASELINE**: valid inference/reference evidence still needed for provenance or comparison.
- **SUPERSEDED**: a valid historical run whose research role is now covered by later runs.
- **FAILED_DIAGNOSTIC**: an attempted intermediate artifact that records a real failure and is useful only for diagnosis.
- **OBSOLETE_PLACEHOLDER**: no model result exists; empty detections, BLOCKED-only visualization, or placeholder prose must not be interpreted as inference.

No whole run is classified `FAILED_DIAGNOSTIC` or `OBSOLETE_PLACEHOLDER`. Those classes occur at artifact level inside otherwise valid runs; see [`CLEANUP_CANDIDATES.md`](CLEANUP_CANDIDATES.md).
