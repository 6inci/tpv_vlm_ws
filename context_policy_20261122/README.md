## 구조

| 단계 | 담당 | 내용 |
|---|---|---|
| 지시 → 항목 | Qwen3-VL-4B (글자만) | 기존과 같다. 시험 15장은 기존 실행의 실제 출력을 쓴다 |
| 후보 박스 | Grounding DINO | 기존 사진 단계 + **작업 공간 띠 확대 검출**(타일 400 px를 2배로) |
| 정체 점수 | SigLIP2 so400m 예시 이미지 | 큐브 / 빈 팔레트 / **큐브가 올라간 팔레트**. 예시는 개발 8장 기준 박스 |

| 받침 | Python + SigLIP | 큐브 후보 둘레(긴 변 × 2.4) crop이 "큐브가 올라간 팔레트"와 닮았는가 |
| 빈 팔레트 | Python + SigLIP | 빈 팔레트 예시 점수 ≥ 기준. 안에 큐브 같은 박스가 없음 |

| 관계(기록) | Python | 후보마다 가장 가까운 5S 구역과 거리(cm) |
| 경로 그림 | `nl_to_route_20261122/nl_to_path.py` 함수 (읽기만) | A·B가 모두 확정일 때 |
