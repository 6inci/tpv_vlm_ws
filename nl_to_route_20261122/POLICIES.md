## 1. 데이터·절차 정책

| 정책 | 지금 | 문제 |
|---|---|---|
| 개발 / 시험 분리 | 개발 8장(옛 카메라, 기준값 결정), 시험 15장(공유 환경) | **15장은 오인 원인을 이미 분석했으므로 더 이상 독립 시험이 아니다.** 규칙을 고친 뒤 독립 시험에는 새 사진이 필요하다 |

| 시험 후 변경 | 정차 규칙과 20 cm 기준을 시험 결과를 보고 바꿈 (README에 기록) | 바꾼 규칙은 새 사진으로 다시 시험해야 한다 |
| 카메라 | 사진 묶음마다 K와 자세가 따로 있다. 개발 8장은 `newK = K`, 15장은 alpha 0 `newK` | 15장의 K는 추정(INFERRED). 팀원 확인 전 |

## 5. 결정 (Python)

| 정책 | 값 | 문제 |
|---|---|---|
| 큐브 확정 | 1위 점수 ≥ 0.88, 겹치지 않는 2위와 차이 ≥ 0.02 | 작업대 물건(0.898)이 기준을 넘었다 |
| 빈 팔레트 확정 | 1위와 2위 차이 ≥ 0.02. **최소 점수 없음** (개발 사진에서 나눌 값이 없었음) | 꼬깔이 1위가 될 수 있다 |
| 빈 팔레트인가 | 큐브 같은 박스(점수 ≥ 0.88)의 중심이 안에 있으면 점유로 보고 뺀다 | |
| 집을 수 있는 것 | `[cube]`만 | |
| 탐색 영역 | 시설을 말하지 않으면(I1) **사진 전체**. 시설을 말하면 확인된 시설 박스 주변(비율 0.6, 최소 120 px) | **작업 공간(매트 바닥, 노란 선 밖 띠) 제한이 없다** |
| 옛 카메라 검사 | "놓지 말 구역 Z01 50% 이상", "주행 구역 5 cm 이내 + 접근 가능". 15장에서는 껐다(옛 카메라 기준이라) | **끈 자리를 고르기 전 단계에서 대신할 규칙을 넣지 않았다** |
| 보류 | 기준 미달이면 A 또는 B를 확정하지 않고 경로도 만들지 않는다 | |
| I2 시설 옆 바닥 | Qwen이 번호 이미지에서 고름 | 0/2, 잘못 확정 1. 쓰지 않는 쪽을 권함 |

## 8. 경로

| 정책 | 값 |
|---|---|
| 지도 | env2_20261119, 1 cm 칸. 4방향 이동 |
| 차체 방향 | 출발 방향과 도착 방향 두 가지. 제자리 회전은 경로당 한 번(팀원 규칙), 출발점에서는 회전하지 않음 |
| 여유 | 몸체 3 cm 이상. 로봇이 지금 선 곳 둘레 5 cm 안은 1 cm 이상이면 지나감 |
| 회전 자리 | 몸체 반대각선 19.0 cm + 3 cm 여유. 회전 중 그리퍼 끝 선(23.1 cm)이 노란 선 안 |
| 비용 | 옆걸음 1 cm = 2 cm, 꺾을 때마다 5 cm, 회전 10 cm |
| 검사 | 팀원 `clearance_check.route_check`로 다시 계산. 불가(여유 < 1 cm 또는 중심 비용 ≥ 253)가 있으면 실패 |
| 문제 | 같은 방향으로 위 통로를 오가면 옆걸음이 최장 215 cm. 팀원은 회전 문제를 고치기 전까지 긴 옆걸음을 피해 달라고 요청함 |
