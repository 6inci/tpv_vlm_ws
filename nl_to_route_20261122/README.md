## 지금 구조가 원하는 모델인가 (판단)

- **흐름은 맞다.** 자연어 → A/B → 좌표 → 경로 → 주행 → 확인 순서이고, VLM은 좌표와 경로를 만들지 않는다.
- **다른 점:**
  - 지금 성공한 결정 중 Qwen의 시각 능력을 쓰는 것은 없다. 물체 판별은 SigLIP 예시 이미지가 하고, Qwen은 글자 해석만 한다.
  - 그 글자 해석도 키워드 표보다 낫다는 근거가 아직 없다(`design_check_20261122`).
  - 따라서 논문에서 "VLM 기반 물체 식별"이라고 쓸 근거는 지금 없다.
  - 근거가 있는 주장은 "VLM 글자 구조화 + 예시 이미지 판별 + 결정론적 기하"다.
- 주장 범위는 사용자가 정한다. Qwen의 역할을 주장하려면 다음 시험이 필요하다.
  - 다양한 지시문
  - 음성 사진: 큐브 없음, 큐브 둘, 빨간 방해물
