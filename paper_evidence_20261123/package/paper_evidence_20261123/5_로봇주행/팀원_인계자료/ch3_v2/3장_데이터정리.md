# 3장 실험 및 결과 — 데이터 정리 (논문 V2 구성 기준, 2026-11-21)

논문 「외부 카메라와 AI Agent를 이용한 자연어 명령의 모바일로봇 주행 목표 변환」 3장 골격(3.1~3.5 + Table 1)에 맞춰,
실제 데이터가 있는 것만 골랐다. 수치마다 상태와 근거 파일을 붙였다. 2026-08 수치(RMSE 1.17 cm, 평균 1.05 cm, 최대 1.57 cm)는 출처를 찾지 못해 넣지 않았다.
V2 원고 파일(`논문초안_V2.hwpx`)에는 3장이 아직 없다. 원고 1·2장 문장과의 대조는 `v2_review/V2_원고_대조.md` 에 있다.

경로는 `~/mecanum/mecanum_data/` 기준(`reports/…`), 패키지 파일은 `~/mecanum/paper_experiment_handoff/` 기준.

## 정리: 3장에 넣을 수 있는 것과 없는 것

- **넣을 수 있음**: 3.1 환경 전체, 3.4 목표 도달(EKF 추정 조건 명시), 3.5 고찰, 3.3 의 '가용성'(주기·검출률).
- **넣을 수 없음(미측정)**: 3.2 인식 성공률·좌표 오차, 3.3 의 11월 위치 정확도, 3.4 의 독립 실측 도착 오차.
- 11/23 전에 3.2·3.3 을 수치로 채우려면 추가 실험 C(대상 좌표 변환)와 A(위치 정확도)가 필요하다 (`minimum_additional_experiments.md`). 못 하면 3.2·3.3 을 '구성과 가용성'으로 줄이고 정확도는 향후 과제로 둔다.
- **V2 원고와 맞출 점**: 2장 ¶2 의 범위 문장(대상 인식·주행 목표 생성·이동)과 새 제목은 3.2 결과를 전제로 한다. 3.2 를 못 채우면 그 문장을 줄여야 한다. 2장 ¶4·¶5 의 '검증' 표현도 3.4 결과(계획기 목표 0/3, 사전 지정 경로만 도달)에 맞춘다 (`v2_review/V2_원고_대조.md` 3절).
