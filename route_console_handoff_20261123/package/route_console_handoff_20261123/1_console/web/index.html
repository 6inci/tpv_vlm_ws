어떤 장면으로 경로를 만들까요?

자연어로 지시하면 옮길 물체와 목적지를 스스로 찾고, 경유점이 담긴 경로를 만듭니다. 사용자가 위치를 찍을 필요가 없습니다.

  1. 지시 이해무엇을 어디로 옮길까?
  2. 장면 인식무엇이 어디에 있을까?
  3. 대상 결정어떤 물체와 목적지를 고를까?
  4. 좌표 변환지도에서 어디일까?
  5. 경로 생성어디에 서고 어떻게 이동할까?
