## 2. 관찰

1. **탐지는 문제가 아닙니다 (CONFIRMED, AI 기준 대비).**
   - DINO는 작은 물체 23개를 모두 찾았습니다. IoU는 큐브 0.63~0.83, 팔레트 0.78~0.92입니다.
   - 다만 DINO 후보 하나에 여러 문구가 붙습니다. 예: 빈 팔레트 하나에 `cardboard box`, `cart`, `container`, `pallet`. 그래서 DINO 문구만으로는 종류를 알 수 없습니다.
2. **작은 팔레트는 SigLIP2도 식별하지 못했습니다 (CONFIRMED).**
   - 빈 팔레트 7개는 모두 1위가 `a metal grate`였습니다(0.39~0.78). `a small pallet`이 2위 안에 든 것은 1번 사진 하나(0.08)뿐입니다.
   - 기준 박스를 그대로 넣어도 같았습니다(7개 모두 `a metal grate`). 따라서 박스 위치 문제가 아니라 **라벨 이름과 실제 모양의 불일치**입니다(INFERRED).
   - 이 받침은 회색 격자 모양이어서 "격자 덮개"에 더 가깝게 보입니다. 이전 Qwen의 `grate`·`manhole cover` 오인과 **같은 실패 유형**입니다.
3. **큐브가 올라간 팔레트는 위의 큐브 이름으로 불렸습니다 (CONFIRMED).**
   - 1위 라벨: `a red cube` 4개, `an orange traffic cone` 3개, `a metal grate` 1개
   - 작업에서 "큐브가 놓인 팔레트"라는 상태를 구분하는 데 SigLIP2 1위 라벨만으로는 부족합니다.
4. **빨간 큐브는 절반만 1위로 맞혔습니다 (CONFIRMED).**
   - 틀린 4개 중 3개는 1위가 `an orange object`였고, `a red cube`는 모두 2위였습니다. 큐브 색이 사진에서 주황빛 빨강으로 보입니다.
   - 같은 큐브라도 DINO 박스(4/8)와 기준 박스(7/8)의 결과가 다릅니다. 20 px 안팎의 물체에서는 박스가 몇 픽셀만 달라도 SigLIP2 판정이 바뀝니다.
   - 2번 사진은 DINO 박스에 받침 격자가 많이 들어가 1위가 `a metal grate`였습니다.
5. **SigLIP2가 "팔레트"라고 부른 것은 적치 구역의 큰 팔레트였습니다 (CONFIRMED: 이름 / INFERRED: 실제 팔레트 여부는 그림 판독).**
   - 사진마다 3~5개, 모두 `a small pallet`이었습니다. 대상은 적치 구역의 드럼통·용기가 올라간 나무 팔레트와 아래쪽 검은 팔레트입니다.
   - 작은 팔레트 15개 중 팔레트로 불린 것은 0개입니다. 그래서 "팔레트를 찾아라"를 SigLIP2 1위로 처리하면 작업 대상이 아니라 적치 구역의 팔레트를 가리킵니다.
6. **큐브로 잘못 부른 후보가 있습니다 (CONFIRMED: 이름 / INFERRED: 실제 물체는 그림 판독).**
   - 왼쪽 위 주황색 선반 옆의 어두운 물체(약 [265, 125, 318, 193])가 사진 3·4·5·6에서 `a red cube`(0.17~0.24)로 불렸습니다.
   - 점수는 실제 큐브(0.50~0.83)보다 낮습니다. 하지만 SigLIP2 점수는 라벨 목록 안의 상대값이므로, 이 차이를 임계값으로 쓰려면 별도 검증이 필요합니다.

## 3. 결론

- **이 설정의 SigLIP2(base, 텍스트 라벨 비교)로 Qwen을 대신해도 작은 팔레트 식별은 개선되지 않았습니다.** 0/15이며, Qwen과 같은 "격자" 오인이 나왔습니다.
- **빨간 큐브는 부분적으로 됩니다.** 1위 4/8, 2위까지 8/8입니다. 기존 시각 뷰어의 "2위 안" 규칙이라면 8개 모두 통과하지만, 그 규칙은 E1에서 정한 값이고 검증되지 않았습니다. 같은 규칙에서 큐브가 아닌 후보가 얼마나 통과하는지는 이번에 재지 않았습니다.
- **Qwen보다 나은지는 이번 실험으로 말할 수 없습니다.** 저장된 Qwen 응답에는 후보 박스가 없어 같은 물체에 연결하지 못했고, Qwen은 이번에 실행하지 않았습니다.
