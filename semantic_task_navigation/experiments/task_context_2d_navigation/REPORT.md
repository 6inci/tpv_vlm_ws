## 8. 다음 실험에서 고칠 것 (이번 실행에서는 수정하지 않음)

1. **관계 해석**: "에서 생산된"(출처)을 "on"(현재 위치)으로 바꾸지 않도록 한다. 명령의 관계어는 v0.2 규칙 파서의 `produced_by`처럼 결정론적으로 뽑고, 출처 관계는 주변 탐색으로 처리한다.
2. **배치 금지 구역**: 목적지 후보의 바닥 위치가 보행자 통로 같은 금지 구역이면 R0·R1 모두 배치 대상에서 제외한다(지도 제약에서 나오는 결정론적 규칙).
3. **영역 수준 박스**: 컨베이어 전체나 넓은 바닥 영역 같은 박스는 배치면으로 보지 않는다. 현재는 영역 대비 50 %만 걸렀다.
4. **기준 물체 검증 예산**: DINO 박스를 IoU로 중복 제거한 뒤 서로 다른 박스만 확인한다.
5. **출발 동률**: 동률 후보만 따로 crop 확인한다. 주황 물체가 빨간 큐브로 평가된 문제.
6. **작은 팔레트의 형태·기능 인식**: 사용자 지시대로 별도 연구로 남긴다. 이번에도 대체 목적지 추론을 막은 직접 원인이다.
