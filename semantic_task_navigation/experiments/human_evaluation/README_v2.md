## 평가하는 것

| 질문 | 언제 | 선택지 |
|---|---|---|
| Q1 이 사진에서 이 작업지시는 성립하는가 | 작업지시마다 한 번, AI 결과를 보기 **전** | 수행 가능 / 의미가 모호함 / 수행 불가능 / 판단 불가 |
| Q2 AI는 옮길 물체를 올바르게 골랐는가 | R0, R1 각각 | 올바름 / 잘못됨 / 적절하게 판단 보류 / 판단 불가 |
| Q3 AI는 작업 맥락을 이해해 적절한 배치 장소를 정했는가 | R0, R1 각각 (세부 점수 없이 한 번) | 적절함 / 부적절함 / 적절하게 판단 보류 / 판단 불가 |
| Q4 경로가 실제 이동 경로로 타당한가 | 경로가 있을 때만 | 타당함 / 부적절함 / 추가 검증 필요 |

- 모든 질문은 "건너뛰기"를 할 수 있습니다.
- 박스 그리기는 필요 없습니다. 원하면 사진에 "옮길 물체" 또는 "놓을 곳" 점을 찍을 수 있습니다(선택).
- AI가 목적지를 고르지 않은 결과도, 보류가 맞았다면 "적절하게 판단 보류"로 평가할 수 있습니다.
- 진단용 경로(출발 후보 동률)에는 그렇게 표시됩니다.

## 순서

1. **안내 화면**: 연구 목적, 네 질문, 헷갈리기 쉬운 개념(운반 대상, 출발/목적지 기준 시설, 실제 배치 목표, 이동로봇, 로봇 정차 위치)을 확인합니다.
2. **"이전 입력 가져오기"**를 누르면 v1에서 저장한 기준을 불러옵니다.
3. **작업지시마다** STEP 1에서 Q1에 답하면 STEP 2(R0 / R1 나란히)가 열립니다.
   - AI가 고른 물체와 배치 목표, 탐색 영역, 판단 이유, 경로 이미지를 보고 Q2–Q4에 답합니다.
   - "저장하고 다음"으로 넘어갑니다.
4. **요약**에서 작업지시별 결과, AI–사람 일치 여부, R0 vs R1 집계를 보고 내보냅니다.

## v1 입력 가져오기

- v1 저장 데이터는 **읽기만** 합니다. 쓰기, 삭제, 초기화는 하지 않습니다(테스트로 확인).
- 가져오면 v1의 "모호성" 선택이 Q1에 미리 채워집니다. 원래 값이 표시되며 바꿀 수 있습니다.

  | v1 모호성 | Q1 |
  |---|---|
  | 명확함 / 허용 대상 여러 개 | 수행 가능 |
  | 명령 자체가 모호함 | 모호함 |
  | 이 장면에서 수행 불가 | 수행 불가능 |
  | 판단 보류 | 판단 불가 |

- v1에서 그린 박스는 각 사진에 흐린 점선으로 보입니다(끄기 가능).
- v1 의견은 Q1 의견란에 들어갑니다. Q2–Q4는 미리 채우지 않습니다.
- 브라우저에서 v1 데이터를 찾지 못하면(다른 브라우저, 또는 Firefox처럼 파일마다 저장소를 나누는 경우), v1 화면 C의 "작업 상태 백업" 파일(`human_evaluation_state.json`)을 **"이전 백업 파일에서 가져오기"**로 불러오세요.

## 저장

| 방식 | 내용 |
|---|---|
| 자동 저장 | 브라우저 저장소, 키 `he_review_v2`. v1 키와 분리 |
| `human_review_v2.json` | 작업지시별 Q1, 조건별 Q2–Q4·의견, 선택적 표시 점, AI 참고값(`ai_reference_not_human`), AI–사람 일치 비교, 가져온 v1 기준(읽기 전용 사본) |
| `human_review_v2.csv` | 조건 10행: Q1–Q4, 경로 유무, 의견, AI 참고값, 일치 여부 |
| `human_review_v2_state.json` | v2 작업 상태 백업 |

내려받은 파일은 `experiments/human_evaluation/results/`로 옮겨 두세요. 모든 답이 채워질 때까지 `status`는 `INCOMPLETE`입니다.

**일치 판정 규칙**

| AI | 사람 | 판정 |
|---|---|---|
| 골랐음 | 올바름 / 적절함 | 일치 |
| 골랐음 | 그 밖의 답 | 불일치 |
| 보류함 | 적절하게 판단 보류 | 일치 |
| 보류함 | 그 밖의 답 | 불일치 |
| (무관) | 판단 불가, 미응답 | n/a |

코드가 "AUTONOMOUS"로 분류했는데 사람이 Q3를 "부적절함"으로 답하면 요약에 ⚠로 표시됩니다.
