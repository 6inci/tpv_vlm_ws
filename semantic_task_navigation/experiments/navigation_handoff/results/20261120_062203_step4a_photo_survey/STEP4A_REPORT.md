# STEP 4-A 사진 8장 분석 보고 (2026-11-20)

- 범위: 읽기 전용 분석입니다. 경로계획(A*)과 모델 호출은 하지 않았고, 기존 지도·코드·결과·패키지는 바꾸지 않았습니다.
- 근거 파일:
  - `survey.json`: 사진별 수치
  - `comparison_8photos.png`: 비교 그림
  - `median_background.png`: 정적 배경(8장의 픽셀별 중앙값)
  - 생성 스크립트: `scripts/survey_photos_step4a.py`
  - 판정 규칙: `config/navigation_config.yaml`의 `step4a`, `step4a_rules`
- 상태 표기: 물체 위치는 모두 AI가 사진에서 읽은 값이므로 `USER_CONFIRMATION_REQUIRED`입니다. 난이도는 아래 측정값에 규칙을 적용한 **예비 판단**이며, A*는 실행하지 않았습니다.

## 1. 공통 사항

- **카메라:** 8장 모두 5번(E1)과 정렬되어 있습니다(v0.2 `check_alignment` ALIGNED, 최대 이동 1.4 px는 1번).
- **정적 환경:** 8장이 같습니다. 노란 주행 영역, 적치 구역 Z04, 박스 더미 Z03, 작업셀, 보행로, 트럭, 콘, 큰 팔레트, 드럼, 소화기 모형이 해당합니다. 예외는 노란 영역 밖의 왼쪽 아래 초록 선반으로, 1·2번에서 위치가 다릅니다.
- **로봇:** 8장 모두 오른쪽 아래에 있고 그리퍼는 이미지 왼쪽을 향합니다.
  - 5번 대비 로봇 영역 이동량: 4~8번은 1 px 이하, 1번은 (−0.4, +4.0) px, 2·3번은 약 (−12.7, +8.1) px(약 2~3 cm)입니다.
  - 저장된 자동 탐지는 4·5·8번에만 있고, 8번 박스는 로봇 일부만 잡았습니다.
- **노란 영역 안의 이동 물체:** 로봇 외에는 없습니다(배경 대비 변화 검출과 육안 확인).
  - 다만 2번 B, 7번 B, 8번 A 팔레트는 **노란선 위에 걸쳐** 있습니다(free 셀 3~5개).
  - 원시 변화 영역에는 카메라가 조금 어긋나 생긴 노란선 가장자리와, 다른 사진에는 있는 물체의 빈자리도 섞여 있습니다. 판정에 쓰지 않았습니다.
- **정적 지도 재사용:** 8장 모두 STEP 2의 map.pgm/map.yaml을 그대로 쓸 수 있습니다. 노란선 위에 걸친 물체는 경로계획 때 사진별 장애물로 추가해야 합니다. 지도 파일은 바꾸지 않습니다.

## 5. STEP 4-B 실행 계획 (승인 후)

1. **위치 확정:** 사진별로 질문하고 답을 받아 기존 승인 파일 형식(`data/approved_positions/photo_N.yaml`)으로 저장합니다. 사용자 제공 좌표와 원본에서 확인한 좌표는 구분해 기록합니다.
2. **사진별 장애물:** 노란선 위에 걸친 물체(8번 A 팔레트 등)와 목표 이외의 이동 물체를 사진별 장애물로 넣습니다. 지도 파일이 아니라 경로계획 단계의 별도 층에 넣으며, 이를 위해 기존 바퀴 경계 스크립트에 사진별 장애물 박스 입력을 추가해야 합니다. 이 변경은 실행 전에 설정에 선언합니다.
3. **경로계획:** 기존 바퀴 경계 모델을 그대로 실행합니다(4방향 A*, 대각선 없음, 여유 2.0 cm 기준, 3.5와 0 cm는 비교용). 알고리즘은 바꾸지 않습니다.
4. **결과:** 사진별 Path A/B, 방향 전환 수, 회전 수, 횡이동 구간, 경로가 없을 때 그 원인과 참고용 최근접 정차 위치, 사진·지도 그림을 냅니다.
5. **이후:** STEP 4-C에서 시나리오별 결과를 비교하고 전달 패키지를 새로 만듭니다(기존 패키지는 그대로 둠).
